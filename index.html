Tiers are ordinal: A teaching-evidenced · B basic-science · C research-active · D clinically-active · E no public evidence found. A high Tier E share is the "ghost roster" signal — directory names with no observable teaching/research/clinical footprint.

Per-school scoring

Columns. Total = raw directory records scraped (the denominator). A–E = tier counts. Ghost rate = 1 − (A+B)/total directory records. Evidence cov. = directory faculty resolved to ≥1 external ID / total. Tier A / dir. = Tier A count / all directory-listed. Active ghost = Tier-E faculty at an active rank / active-rank faculty (n/a when rank text is too sparse to be representative). Bus factor = smallest count of active (Tier A+B) faculty across the ten canonical biomedical disciplines; < 2 is flagged.

Generated from faculty_adequacy.reporting.national_report — metrics via faculty_adequacy.scoring (ratios.py, bus_factor.py). Colors validated colorblind-safe (dataviz palette validator, light + dark). This reflects what public federal / scholarly sources currently show — not a judgment of any institution's quality of instruction.
