Tiers are ordinal: A teaching-evidenced · B basic-science · C research-active · D clinically-active · E no public evidence found. A high Tier E share is the "ghost roster" signal — directory names with no observable teaching/research/clinical footprint.

Read Tier A as a coverage measure

Tier A is earned only by being named in a public curriculum document (course / block / clerkship director). Those documents have to be located and curated per school before anyone at that school can reach Tier A. Right now 57 of 73 schools in this table (78%) have a curriculum source; Tier A is only measurable for those.

For the remaining 16 schools, Tier A shows as n/m — not measured, which is not the same as "no teaching faculty". Curating one more curriculum URL raises the national Tier A count without anything changing at the schools themselves, so do not compare Tier A between a school that has a curriculum source and one that does not. The Curric. source column below marks which is which.

Per-school scoring

Columns. Total = raw directory records scraped (the denominator). Curric. source = whether a public curriculum document has been curated (dci_url / syllabus_url / course_catalog_url) or curriculum evidence already harvested — Tier A is measurable only where this is yes; where it is no, Tier A renders n/m (not measured). A–E = tier counts. Ghost rate = 1 − (A+B)/total directory records. Evidence cov. = directory faculty resolved to ≥1 external ID / total. Tier A / dir. = Tier A count / all directory-listed. Active ghost = Tier-E faculty at an active rank / active-rank faculty (n/a when rank text is too sparse to be representative). Bus factor = smallest count of active (Tier A+B) faculty across the ten canonical biomedical disciplines; < 2 is flagged.

Generated from faculty_adequacy.reporting.national_report — metrics via faculty_adequacy.scoring (ratios.py, bus_factor.py). Colors validated colorblind-safe (dataviz palette validator, light + dark). This reflects what public federal / scholarly sources currently show — not a judgment of any institution's quality of instruction.
