Tiers are ordinal: A teaching-evidenced · B basic-science · C research-active · D clinically-active · E no public evidence found. A high Tier E share is the "ghost roster" signal — directory names with no observable teaching/research/clinical footprint.

Read Tier A as a coverage measure

Tier A is earned only by being named in a public curriculum document (course / block / clerkship director). Those documents have to be located and curated per school before anyone at that school can reach Tier A. Right now 122 of 174 schools in this table (70%) have a curriculum source; Tier A is only measurable for those.

For the remaining 52 schools, Tier A shows as n/m — not measured, which is not the same as "no teaching faculty". Curating one more curriculum URL raises the national Tier A count without anything changing at the schools themselves, so do not compare Tier A between a school that has a curriculum source and one that does not. The Curric. source column below marks which is which.

What this cloud can and cannot tell you

38 of 174 schools clear the reliability gates (≥100 directory records, ≥50% evidence coverage, ghost-rate confidence interval ≤ 15 pp). The other 136 are hidden by default — many are 20–99-record single-department scrapes whose "0%" is a scraping artifact, not a finding. Untick Reliable schools only to show them as hollow marks.

Compare within an accreditor. DO (COCA) rosters are small and mostly preclinical while LCME rosters include thousands of clinical affiliates, so the two groups sit at structurally different heights and a pooled correlation is largely a between-group effect. Per-accreditor ρ is reported separately below the chart.

The Y axis divides by roster size. A school that lists every clinical affiliate mechanically scores lower than one that lists only its core faculty — which is why Directory records is offered as an X, so you can see that relationship rather than mistake it for a finding.

NIH dollars here are not institutional totals. They are active awards (FY ≥ 2025) held by directory faculty we matched, so a school with a partial roster or a poor match rate looks poorer than it is. 100 of 174 schools have any matched active award; the rest are not plotted on that axis rather than being piled at zero. Enrollment is available for 171 of 174.

Color and dot size are descriptive, not evidence. Color by repaints the same dots by accreditor, US Census region, or school size — it adds no data and fits nothing, it only lets you check whether an apparent pattern is really a group effect. Shape always means accreditor and hollow always means "below the gates", in every color mode, so no signal is ever carried by hue alone; each legend key is also a button that isolates its group. School size is MD + DO enrollment where we have it and directory-roster size where we do not — two different units on one scale, flagged in the tooltip whenever the fallback is in play, so a large roster is not misread as a large student body. Size dots by school size scales the radius by the square root of that value (area, not radius, is proportional) and is independent of the color choice.

Per-student Tier-A/Tier-A+B ratios are deliberately not offered as a Y: they divide by enrollment, so plotting them against enrollment would manufacture a correlation. No trend line and no p-values are drawn — ρ is a rank correlation, shown only at n ≥ 10, and it is descriptive. Tier A also still measures curriculum-document curation as much as it measures faculty (see the caveat above), which is why Any-evidence share is offered as a curation-independent alternative.

At a glance

Teaching-evidenced share against four fixed measures, obeying the filters and the Color by choice above so every panel agrees with the explorer and shares its legend. Dot size is fixed here whatever the explorer is doing — at this scale bubbles only overlap.

Per-school scoring

Columns. Total = raw directory records scraped (the denominator). Curric. source = whether a public curriculum document has been curated (dci_url / syllabus_url / course_catalog_url) or curriculum evidence already harvested — Tier A is measurable only where this is yes; where it is no, Tier A renders n/m (not measured). A–E = tier counts. Ghost rate = 1 − (A+B)/total directory records. Evidence cov. = directory faculty resolved to ≥1 external ID / total. Tier A / dir. = Tier A count / all directory-listed. Active ghost = Tier-E faculty at an active rank / active-rank faculty (n/a when rank text is too sparse to be representative). Bus factor = smallest count of active (Tier A+B) faculty across the ten canonical biomedical disciplines; < 2 is flagged. Reliable = clears all three correlation-explorer gates (≥100 directory records, ≥50% evidence coverage, and no Phase-7 insufficient data flag on ghost rate, i.e. a bootstrap CI no wider than 15 pp); only these schools are plotted by default above.

Explorer measures. Teaching-evidenced share = (Tier A + B) / total directory records = 1 − ghost rate. Any-evidence share = (A + B + C + D) / total — the share of directory names with any observable teaching, research, or clinical footprint, and the measure least sensitive to how well department text parses. Active NIH $ via matched faculty = the sum of active NIH awards (FY ≥ 2025) held by directory faculty resolved to a RePORTER profile, deduplicated per project — not an institution's NIH portfolio, and therefore depressed wherever a roster or its entity resolution is incomplete.

Explorer encodings. Shape = accreditor (circle LCME / diamond COCA) and hollow = below the reliability gates, in every mode — those two never move. Color by is a view control only: Accreditor (redundant with shape on purpose), Region = the US Census four-region grouping derived from the school's state, with territories and unknown states folded into a neutral Other rather than a fifth hue, and School size = five quintile buckets of MD + DO enrollment, falling back to directory-roster size where enrollment is unknown (flagged in the tooltip — the two are different units). Size dots by school size scales each dot's area to that same value (radius ∝ √value), bounded so the smallest dot stays clickable. Clicking a legend key isolates that group; clicking it again clears. Palette slices are validated colorblind-safe for scatter (all-pairs) in light and dark; the four-region set sits in the documented 6–8 warn band under simulated protanopia in dark mode, which is why the legend, the tooltip and the St column below all name the group in words.
